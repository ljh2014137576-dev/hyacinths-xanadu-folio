# Xanadu Code Flow Browser

Xanadu 式代码流程浏览器面向需要理解陌生项目和跨文件调用关系的开发者。它从用户选择的入口出发，把向外引用的函数源码组合为可追溯的流程页，并用可见桥梁连接具体调用位置与目标定义。

当前仓库处于 MVP 0.1 启动阶段。第一阶段只实现静态代码浏览，不包含断点、变量值、实时执行轨迹、线程、进程或时间线调试。

## 产品原则

- 源码片段是视觉主体，关系只作为辅助表达。
- 默认只从入口沿向外引用展开，不自动混入无关的入站调用者。
- 每条引用关系都必须能追溯到精确源码位置和解析结果。
- 循环体只建模一次；静态次数只能表示上限、表达式或未知。
- 语言能力通过 `LanguageAdapter` 接入，核心模型不绑定单一语言。
- 标准视图和沉浸式视图共享同一流程页状态。

## 开发状态

架构分析、实现与审查通过独立分支和 Pull Request 顺序推进。安装、启动、测试与构建命令将在 MVP 纵向切片落地后补充并由 CI 验证。
